## PPTX 還原方式

由於目前 ChatGPT GitHub Connector 僅能直接寫入 UTF-8 文字，本版本以 Base64 分片保存原始 PPTX bytes。

Windows PowerShell：

```powershell
./REBUILD_PPTX.ps1
```

輸出：

`VPO_高階行政決策工作流_個案競賽版_12+5頁.pptx`

還原後請核對 `SHA256.txt`。
